# AlmazovQwiz Beta 3.1.0 — TEXTBOOK GRANULAR

## Что изменено
- Материал, который уже был проверен по загруженному тому I Гайворонского, теперь разложен в отдельные мини-наборы по конкретным темам.
- Общие банки по остеологии/артрологии/миологии дополнительно разбиты по `topicKey`, чтобы в одном наборе не смешивались соседние темы.
- Проверенные карточки не заменены догадками: версия 3.1 не добавляет непроверенные факты под видом материала учебника.
- Версия приложения и Service Worker обновлены до 3.1.0.

## Важно
Это структурный этап. Следующий этап — последовательное извлечение новых фактов из глав загруженных томов, с отдельной проверкой каждого фрагмента. Для сканированных страниц дословные цитаты и страницы не создаются автоматически без проверки изображения/распознанного текста.
