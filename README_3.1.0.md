# AlmazovQwiz 3.1.0

Гранулярная версия учебниковой базы. Основана на уже проверенных данных AlmazovQwiz и загруженного тома I Гайворонского.

## Установка на GitHub Pages
Загрузите содержимое ZIP в корень репозитория. Не переименовывайте `index.html`, `app.js` или `sw.js`.

После обновления при необходимости выполните жёсткое обновление страницы/очистку данных сайта, чтобы старый Service Worker не держал предыдущую версию.
