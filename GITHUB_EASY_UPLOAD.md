# GitHub Easy Upload

В этой сборке обложки наборов встроены прямо в `app.js` как data URI.
Отдельно загружать `assets/covers/` не нужно.

Если GitHub с телефона позволяет загружать только по одному файлу, достаточно заменить `app.js` на этот из архива. Остальные файлы структуры проекта загружаются как обычно.
