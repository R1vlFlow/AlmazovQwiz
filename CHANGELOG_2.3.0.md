# AlmazovQwiz Beta 2.3.0

## Структура наборов
- Добавлены системные подразделы: мозговой/лицевой отделы черепа; шейный/грудной/поясничный отделы позвоночника; крестец и копчик; рёбра и грудина; плечевой пояс; плечо и предплечье; кисть; тазовый пояс; бедро; голень; стопа.
- Для каждой исходной анатомической темы создан отдельный глубокий набор.

## Карточки
- Исправлены формулировки структурных вопросов: ответ больше не содержится буквально в тексте вопроса.
- Добавлены пояснения после ответа.
- Алгоритм перемешивания учитывает тему, тип карточки и предыдущий ответ, снижая вероятность зеркальных пар.

## Создание наборов
- Исправлена ошибка счётчика карточек после удаления: номер теперь пересчитывается по фактическим DOM-карточкам.
- При открытии страницы создания всегда начинается с одной карточки.

## Визуал
- Добавлены оригинальные SVG-обложки для анатомических наборов.
- Обложка теперь сразу показывает регион/структуру, а не одну и ту же иконку кости.

## Навигация
- В учебной сессии появилась кнопка «Предыдущая» без разрушения порядка сессии.
- Выход из сессии корректно завершает статистику и возвращает к наборам.
