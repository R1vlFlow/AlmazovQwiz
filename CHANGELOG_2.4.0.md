# AlmazovQwiz 2.4.0

- Исправлена вкладка «Знания»: больше нет ссылок на несуществующие наборы.
- Основной каталог перестроен в системные разделы без дублирования legacy-наборов.
- Добавлен профессиональный банк анатомии по 11 системным разделам и отдельный визуальный банк.
- Карточки получили структуру: термин, определение, топография, функция, практический акцент и источник.
- Улучшен алгоритм тестов: избегает зеркальных пар, повторяющихся ответов и однотипных карточек подряд.
- Визуальные вопросы используют numbered/public-domain/CC Wikimedia diagrams.
- Обложки системных наборов переработаны в единый медицинский дизайн с различимыми визуальными мотивами.
- Исправлен Service Worker для GitHub Easy: он больше не требует отсутствующие assets/cards и assets/covers.
- Точные цитаты учебника не генерируются из памяти: для привязки цитаты к странице нужен сам файл соответствующего тома.
