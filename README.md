# AlmazovQwiz Beta 2.0.0

Профессиональный локальный MVP системы знаний: наборы, карточки, режимы изучения, написание, тест и экзамен, интервальное повторение, карта знаний, аналитика, локальная библиотека учебников и создание карточек из разделов.

## Данные
- Прогресс меняется только после реального ответа.
- Пользовательские данные хранятся локально.
- Резервная копия доступна в Профиле.
- Версионированный Service Worker очищает старый технический кэш при обновлении.

## Учебники
Поддерживаются PDF с текстовым слоем, DOCX и TXT. Сканированные PDF без текстового слоя требуют OCR и не выдаются за автоматически распознанные.

## Ограничения MVP
Серверной авторизации, облачной синхронизации и реального внешнего ИИ API нет. Генерация карточек из учебника использует локальный эвристический разбор; это намеренно обозначено как автоматическое создание, а не как подтверждённая ИИ-генерация.
