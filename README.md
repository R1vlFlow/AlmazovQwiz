# AlmazovQwiz Beta 2.1.0

Профессиональная библиотека карточек на основе загруженного учебника «Анатомия человека» И.В. Гайворонского.

В сборке: 7 тематических наборов, более 100 карточек, русско-латинские карточки, написание, тест, экзамен, визуальные карточки с изображениями из тома 1, источники и привязка к главам.

Том 2 загружен как скан без доступного текстового слоя; поэтому в этой сборке добавлен только небольшой стартовый набор по началу главы 1. Полное покрытие тома 2 следует выполнять отдельным OCR-процессом с проверкой распознавания.
