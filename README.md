# AlmazovQwiz — Beta 1.2.0

Базовое техническое обновление.

## Исправлено
- светлая, тёмная и системная темы;
- настройки профиля;
- Telegram-поддержка `@R1vlFlow_GY`;
- навигация и обработчики кнопок;
- раздел «Создать набор»;
- уведомление об отсутствии новых уведомлений;
- ручной сброс локальных данных;
- ручное обновление кэша;
- автоматическое обнаружение новой версии;
- автоматическое удаление старого технического кэша при обновлении;
- новая версия Service Worker.

## Важно
Пользовательские наборы и статистика хранятся в `localStorage` и не удаляются при обычном обновлении версии.
При выборе «Сбросить локальные данные» они удаляются намеренно.
