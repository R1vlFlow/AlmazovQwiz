# МедКвест 1.3

Программа анатомии первого семестра: 15 занятий по 4 часа, четыре раздела и по 12 вопросов на занятие. Карточки без самооценки, выбор и ввод ответа, сохранение занятия и повтор ошибок. Дополнительно доступны 84 интерактивных задания и атлас из трёх научных таблиц.

Техническая версия — 4.3.0, продолжение AlmazovQwiz. Старые 4 246 карточек и локальный прогресс сохранены. Новые задания — пилот, без независимой экспертной рецензии. Полная папка Drive не импортирована.

## Запуск и данные

Разместите файлы на статическом HTTP-сервере или GitHub Pages. Приложение не требует сборки и внешних библиотек. Service Worker работает на HTTPS и localhost; после первой загрузки можно учиться без интернета. Для обновления откройте страницу с интернетом и перезагрузите её после установки новой версии.

Данные хранятся на устройстве; аккаунтов, облачной синхронизации и платежей нет. В профиле можно скачать и восстановить резервную копию, включая квесты. Загруженные учебники в копию не входят.

## Разработка

- `data/curriculum.js`: темы, часы, вопросы и источники программы; итоговый набор повторяет 12 вопросов.
- `curriculum.js`, `curriculum.css`: программа семестра и единый интерфейс карточек, проверки и ввода ответа.

- `data/quests.js`: новые маршруты, задания и ссылки на источники.
- `anatomy-data.js`, `anatomy.js`, `anatomy.css`: анатомический атлас, 22 структуры и 44 задания. Авторство и лицензии: `assets/anatomy/ATTRIBUTION.md`.
- `visual-learning.js`: собственные рисунки и вопросы с активными точками; `learning-v2.js`, `learning-v2.css`: обновлённые карточки и плитки.
- `quest-core.js`: проверка ответов и валидация сохранений; `quests.js`, `quests.css`: интерфейс квестов.
- `data/bank.json`: прежний банк; `npm run build` обновляет `data/bank.js`.
- `app.js`, `library.js`, `ui.js`: прежнее обучение, библиотека и настройки.
- `npm run check`: синтаксис; `npm test`: 30 проверок (Node.js 22+). Проверки запускаются в GitHub Actions.
- `node --test tests/*.test.cjs`: запуск тестов без npm.

Ключи `aq_state` и IndexedDB сохранены намеренно для совместимости. Новый интерфейс не означает повторную предметную проверку всего старого банка; см. [аудит](CONTENT_AUDIT.md).

# AlmazovQwiz Beta 2.4.0

Обновлённая система карточек для анатомии.

## Что изменено

- Новая шторка выбора режима вместо обычного select: **Изучение, Карточки, Тест, Экзамен, Написание**.
- В тестах и экзаменах создаётся отдельная случайная последовательность.
- Алгоритм перемешивания старается не ставить подряд карточки одной темы и одного типа.
- Тест: до 12 вопросов; экзамен: до 20 вопросов.
- Кнопка «Случайный вопрос» внутри сессии.
- Навигация «Назад» не возвращает случайно выбранный старый вопрос браузерной историей: она корректно завершает текущую сессию и возвращает к наборам.
- Добавлены отдельные тематические наборы:
  - Череп
  - Позвонки
  - Рёбра и грудина
  - Скелет верхней конечности
  - Скелет нижней конечности
  - Осевой скелет
- Добавлены 274 карточки в новых наборах, включая визуальные вопросы.
- Визуальные карточки поддерживают маркер выделенной области.
- Визуальные изображения подключены из Wikimedia Commons с открытыми лицензиями; источники указаны ниже.
- Старая широкая база и существующие наборы сохранены.

## Структура

- `index.html` — оболочка приложения
- `app.js` — логика, банк карточек, алгоритм сессий
- `styles.css` — интерфейс
- `sw.js` — Service Worker
- `assets/cards/` — текущие изображения учебника


### GitHub Easy mode
В этой сборке изображения из `assets/cards/` встроены непосредственно в `app.js`. Отдельно загружать файлы `assets/cards/*.jpg` не требуется.
